# Image Remover Tool  

An online tool for removing backgrounds from images effortlessly.  

## Features  
- **Multiple Image Uploads:** Upload and process multiple images at once.  
- **Custom Background Colors:** Choose any background color or keep it transparent.  
- **Real-Time Preview:** See live previews of the background removal process.  
- **Beautiful UI/UX:** Sleek design with smooth animations and micro-interactions.  
- **Dark Mode Support:** Switch between light and dark themes for better usability.  
- **Fully Responsive:** Optimized for desktop, tablet, and mobile devices.

## Installation  
1. Clone the repository:  
   ```bash
   git clone https://github.com/your-username/imageremover-tool.git
   cd imageremover-tool
   ```
2. Install dependencies:  
   ```bash
   npm install
   ```
3. Start the development server:  
   ```bash
   npm start
   ```  

## Usage  
1. Upload one or multiple images.  
2. Choose a custom background color or keep it transparent.  
3. Preview the changes in real-time.  
4. Download the processed images.
